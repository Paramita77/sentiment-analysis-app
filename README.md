# 🎬 Movie Review Sentiment Analysis

An NLP-based sentiment analysis tool that classifies movie reviews as **Positive** or **Negative** using Machine Learning.

## 📌 Features

- Text preprocessing (HTML tag removal, normalization)
- TF-IDF based feature extraction
- Logistic Regression model for classification
- Interactive web app built with Streamlit
- Achieves **89.49% accuracy** on test data

## 🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit

## 📊 Dataset

IMDB Dataset of 50K Movie Reviews (from Kaggle)

## 🚀 How to Run Locally

1. Clone this repository
2. Install dependencies:
   pip install pandas scikit-learn nltk streamlit joblib
3. Run the app:
   streamlit run app.py
